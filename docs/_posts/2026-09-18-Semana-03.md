En esta tercera semana el objetivo es comenzar a implementar sondas específicas para poder monitorizar el tiempo que pasa el alumno editando, ejecutando y estudiando en la web de [UNIBOTICS](https://unibotics.org/login?next=/apps). 

Durante esta semana he investigado y probado cómo sería el funcionamiento de las sondas. El flujo sería el siguiente:

1. Acción del Usuario: El estudiante pulsa el botón "Play" en la interfaz.

2. Captura en React: El componente playpause.tsx intercepta el clic, verifica que el código es válido y lo manda a ejecutar al contenedor RADI.

3. Emisión de la Sonda: Inmediatamente después de que la ejecución arranca con éxito, React dispara una función en segundo plano que envía un paquete de datos JSON a Django (ej. {"evento": "start_execution", "timestamp": "11:15:00"}).

4. Recepción en Django: Una ruta (endpoint) específica en Django recibe ese JSON.

5. Persistencia: Django asocia ese evento con la sesión del usuario actual y lo guarda en la base de datos para que luego pueda ser analizado o visualizado en las herramientas de métricas de los profesores
